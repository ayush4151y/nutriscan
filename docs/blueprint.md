# **App Name**: NutriScan Analyzer

## Core Features:

- Ingredient Extraction: Capture ingredient data via image or barcode and use OCR to automatically extract ingredient names and quantities.
- AI-Powered Health Analysis: Utilize a generative AI tool to classify ingredients (healthy/moderate/harmful), calculate quantity-based health ratings, and provide personalized warnings based on user profiles.
- Personalized Health Profiles: Enable users to input allergies and health concerns to personalize the AI analysis and warnings.
- Alternative Suggestions: Suggest alternative products with better health ratings using AI analysis of comparable products.
- Workflow Integration: Orchestrate the app flow between camera, AI models, and the result display.

## Style Guidelines:

- Primary color: Fresh Mint Green (#98FF98) to convey health and freshness.
- Background color: Very Light Mint Green (#F0FFF0), almost white, for a clean, unobtrusive backdrop.
- Accent color: Muted Raspberry (#BC8F8F) for warnings and important alerts; its contrast to the analogous greens of the design will highlight potentially harmful ingredients and call attention to personal recommendations.
- Headline font: 'Belleza' sans-serif for an engaging and attractive aesthetic.
- Body font: 'Alegreya' serif font, providing clear and elegant presentation of nutritional and health-related information. Using a contrasting font for the body and headline is more suitable than using a singular font given that blocks of texts exceeding a paragraph are anticipated in the nutritional facts and details. 
- Use health-related icons that clearly represent ingredient categories and health impacts.
- Implement subtle animations to enhance the user experience during scanning and analysis, providing real-time feedback.
